ForeverSensei Fonts
===================

ipagui.ttf - IPA UI Gothic (IPAUIGothic, version 002.03), by the Information-technology Promotion Agency, Japan (IPA).
Licence: IPA Font License Agreement v1.0, full text in IPA_Font_License_Agreement_v1.0.txt (this folder).
The file is unmodified. The WoW Forever Japanese addon bundles the same font under the same name
(github.com/zyaga/wow-forever-japanese, addon/WoWForeverJapanese/Fonts).

Why: the default English game fonts have no Japanese glyphs. ForeverSensei uses WoW Forever Japanese's copy of
this font when that addon is loaded, and this copy otherwise.

The IPA Font License is not the GPL: the font stays under its own licence; the rest of ForeverSensei is
GPL-2.0-or-later.
